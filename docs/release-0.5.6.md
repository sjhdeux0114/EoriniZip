# 어린이zip 0.5.6 · Windows 설치 업데이트

설치 프로그램이 현재 Windows 사용자에게 등록된 어린이zip 정식판과 예전 테스트판을 확인합니다. 먼저 두 설치의 제거 가능 여부를 확인한 다음, 각 버전의 제거 프로그램이 완료된 후 새 버전을 설치합니다. 이전 버전을 이미 제거했다면 신규 설치로 진행합니다.

기본 설치 위치는 `%LOCALAPPDATA%\Programs\EoriniZip`입니다. 이전 설치에 사용했던 임시 폴더를 자동으로 다시 선택하지 않습니다. 설치 마법사에서 다른 위치를 선택할 수 있습니다.

기존 앱이 실행 중이면 앱을 닫고 다시 시도할 수 있습니다. 이전 설치의 위치와 제거 프로그램을 확인할 수 없거나 더 최신 버전이 설치되어 있으면 진행을 중단합니다. 등록된 사용자 설치의 업데이트는 일반 사용자 권한으로 실행합니다.

## Windows 검증 기록

- 별도의 테스트 ID로 0.5.1 정식판과 테스트판을 서로 다른 폴더에 설치한 뒤 0.5.6으로 업그레이드했습니다. 이전 실행 파일 두 개가 제거되고 설치된 앱에는 0.5.6 하나만 남았습니다. 이전 폴더에 별도로 만든 사용자 파일은 보존됐습니다.
- 기존 실행 파일을 잠근 상태에서 업그레이드를 시도했을 때 두 설치가 모두 보존됐고, 잠금을 해제한 후 다시 실행해 업그레이드를 완료했습니다.
- 동일한 폴더에 우클릭 메뉴 DLL을 잠근 상태로 재설치한 경우와, 이전 버전을 제거한 상태에서 새로 설치한 경우를 확인했습니다. 새 버전도 정상 제거됐습니다.

설치 테스트에는 버전별 설치 스크립트와 실제 앱 파일을 사용하고, 기존 사용자 환경과 겹치지 않도록 테스트 ID와 디렉터리를 분리했습니다. 테스트에서 실제 탐색기 메뉴 등록은 제외했습니다. 압축을 풀어 별도로 보관한 포터블 복사본은 자동 제거 대상에 포함되지 않습니다.
