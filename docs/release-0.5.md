# 어린이zip 0.5

Windows x64 개발 릴리즈입니다. 설치 파일은 EoriniZip-0.5-windows-x64-setup.exe입니다.

- 노란색 네이티브 화면, 폴더 트리, 최근 파일, 목록 정렬, 파일 끌어놓기.
- ZIP/7Z/TAR/ZPAQ 압축 및 ALZ/EGG/RAR 해제, EasyCrypt 2.4 복호화.
- 암호 파일 열기·우클릭 해제 시 암호 입력 및 재시도 경로, 컴팩트 진행 창.
- 파일명 충돌 시 (1), (2)로 보존. 압축 임시 작업은 OS TEMP에서 수행.
- 단일 ZIP/7Z 내부 파일 추가·삭제·이름 변경과 수정본 무결성 검사.
- 이미지·텍스트 미리보기, 파일 연결 전체 선택/해제, 설정 가져오기/내보내기.
- 각각 압축/해제, ZIP 내부 파일 목록·아이콘의 클래식 우클릭 미리보기.

검증: Windows 네이티브 빌드, 코어/메뉴/대화상자 리소스 검사, 실제 엔진 암호·한글·충돌·편집·취소 검사, ZIP/7Z/ALZ/EGG/RAR4/RAR5 분할 정상/누락/손상 검사, 제공된 EasyCrypt 파일의 원본 바이트 일치, 교차 드라이브 압축 결과 저장, 별도 ID 설치·제거 검증.

7-Zip 26.05를 포함하며 2026-10-31 RustSec 검사 및 외부 코덱 최신 커밋 대조를 통과했습니다. 라이선스와 7-Zip 소스를 설치 패키지에 포함합니다.

## 알려진 제한

- 비밀번호 창의 실제 입력·취소·재입력 조작 및 최신 미리보기 화면은 화면 도구 초기화 오류로 검증하지 못했습니다. 엔진 경로 및 실제 대화상자 리소스 검사와 구분됩니다.
- 현재 PC는 Windows 10입니다. Windows 11 첫 우클릭 메뉴는 구현/패키지 생성만 완료했으며 실제 등록은 OS 버전 조건으로 거부됐습니다. 설치 파일은 클래식 메뉴(Windows 11의 더 많은 옵션)를 등록합니다.
- Mac 실행, ARM64/Windows PE, 코드 서명/공증은 미검증입니다. 이 릴리즈의 설치 파일은 Windows x64용입니다.
- 전체 반디집 기능이 완성된 버전은 아닙니다. 상세 환경설정, 암호 관리자/복구, 손상 ZIP 복구, 악성코드 검사, 클립보드 파일 작업, 압축 설명, 추가 생성 포맷, 자동 업데이트는 남아 있습니다.
- AESLocker는 지원하지 않습니다. RAR/ALZ/EGG는 읽기·해제 전용입니다. ZIP 분할 생성은 .001 방식입니다.
- 비밀번호는 설정/로그에 저장하지 않지만 엔진 인수 전달 방식의 개선이 남아 있습니다.
