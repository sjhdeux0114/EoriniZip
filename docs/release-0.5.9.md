# 어린이zip 0.5.9 · Windows x64

- 압축 파일 내부에서 원하는 폴더나 선택한 파일만 바로 압축 해제할 수 있도록 툴바에 **선택 풀기** 버튼과 `Ctrl+Shift+E` 단축키를 추가했습니다.
- 왼쪽 폴더 트리 및 오른쪽 파일 목록에서 우클릭 컨텍스트 메뉴(**이 폴더만 압축 풀기...**, **선택한 항목 풀기...**, **현재 폴더만 압축 풀기...**, **전체 압축 풀기...** 등)를 지원합니다.
- 오른쪽 목록에서 별도 선택이 없을 때 **선택 풀기**를 실행하면 왼쪽 트리에서 선택한 현재 폴더만 압축 해제합니다.
