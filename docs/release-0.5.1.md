# 어린이zip 0.5.1 개발 릴리즈

2026-11-01, Windows 11 x64와 macOS CI에서 작업했습니다. 공인 코드 서명·Mac 공증을 완료한 일반 배포판이 아닙니다.

## 변경

- Windows 11 첫 메뉴용 signed sparse MSIX의 설치·제거 경로와 진단 스크립트. 버전별 탐색기 DLL 파일명으로 기존 DLL 잠금 충돌을 줄였습니다.
- 첫 메뉴의 어린이zip 하위 명령을 클래식 메뉴 기능과 맞췄습니다. 단일 압축 파일, 일반 파일, 폴더, 여러 압축 파일, 혼합 선택을 구분합니다. ZIP은 탐색기에서 폴더 속성도 가지므로 스트림 속성을 함께 검사합니다.
- macOS NFD 한글/악센트 파일명 NFC 정규화, 원래 내부 이름으로 선택·편집, 조합된 이름으로 해제·표시. 정규화/유니코드 대소문자 충돌을 거부합니다.
- 클립보드 파일 복사/붙여넣기, 텍스트 외부 편집 후 ZIP/7Z 반영, ZIP UTF-8 설명 편집.
- Windows 자격 증명 저장·불러오기·삭제와 사용자 제공 암호 후보 목록 검사.
- 제한된 ZIP 중앙 디렉터리 복구와 Microsoft Defender 검사 연결.
- 글꼴·칼럼·툴바·임시 폴더 설정, 한국어/영어 기본 UI 선택, 서명자 검증이 있는 업데이트 경로.
- GZIP/BZIP2/XZ 단일 파일, WIM 비압축, 7Z SFX, 비부팅 ISO 생성.
- 폴더 이름의 [폴더] 접두어를 제거하고 Windows 기본 폴더/파일 아이콘을 표시합니다. 왼쪽 폴더 트리와 Mac 목록에도 아이콘을 표시합니다.

## Mac 설치 파일

- Apple Silicon: EoriniZip-0.5.1-macos-arm64.dmg / .zip
- Intel: EoriniZip-0.5.1-macos-x86_64.dmg / .zip
- 최소 배포 대상은 macOS 13입니다. DMG에서 EoriniZip.app을 Applications로 드래그해 설치합니다.
- 앱 안에 공식 7-Zip 26.05와 ALZ/EGG/ZPAQ/EasyCrypt 코덱·라이선스를 포함하고, 포함한 엔진을 자동 연결합니다.
- Mac은 ad-hoc 서명이며 Apple Developer ID 서명·공증은 없습니다. Windows 테스트 인증서는 Mac용이 아닙니다.

## 검증 범위

- 최종 소스 9e104e6의 [Windows/macOS CI](https://github.com/sjhdeux0114/EoriniZip/actions/runs/41254697397), [Mac 두 CPU 패키징](https://github.com/sjhdeux0114/EoriniZip/actions/runs/41254697409), [보안 의존성 검사](https://github.com/sjhdeux0114/EoriniZip/actions/runs/41254697385) 통과.
- Mac arm64/x86_64에서 앱·코덱 빌드, 코어/실제 압축 통합/분할 검사, 번들 내부 엔진으로 통합 검사 재실행, Mach-O 아키텍처/외부 라이브러리 경로 검사, ad-hoc 서명 검증과 DMG 무결성 검사를 통과했습니다.
- 배포 ZIP을 다운로드해 무결성을 검사했고 DMG/ZIP SHA-256이 CI 체크섬과 일치합니다.

- 네이티브 앱·코덱·메뉴 DLL 빌드와 코어/클래식 메뉴/Windows 11 메뉴/대화상자 리소스 검사.
- 실제 7-Zip 26.05 및 네이티브 코덱으로 압축 왕복, 암호·오암호, 한글 NFD/NFC, 선택 해제, 충돌 번호 저장, 취소, 편집 실패 시 원본 보존.
- 외부 편집용 교체는 암호화 ZIP/7Z와 내부 하위 폴더 경로를 검사합니다. ZIP 설명은 한글 왕복·오암호 시 원본 보존·크기 제한을 검사합니다.
- 추가 포맷의 내용 왕복, SFX의 암호화 헤더, ISO의 한글 이름, 사용자 지정 임시 폴더 정리를 검사합니다. 생성된 SFX 자체를 실행하지 않고 엔진으로 검사합니다.
- ZIP 중앙 디렉터리 누락 복구, 데이터 CRC 오류 결과 미게시, 원본 보존.
- Windows 자격 증명의 한글 암호 저장·조회·교체·삭제. CF_HDROP 유니코드·긴 경로·여러 파일·빈 선택 검사는 통과했습니다. 실제 클립보드 왕복은 전용 window station을 새로 만들 수 없는 환경에서 종료 코드 77로 명시적 skip하며 사용자 클립보드를 변경하지 않습니다.
- 업데이트 서명 조건 검사와 실제 서명 EXE의 바이트를 변경한 HashMismatch 차단. 이 PC의 로컬 인증서 서명은 Authenticode Valid를 확인했습니다.
- 실제 Microsoft Defender 명령으로 생성한 테스트 ZIP을 검사하여 정상 종료와 무탐지 보고를 확인했습니다.
- ALZ/EGG/RAR4/RAR5/ZIP/7Z 분할 정상·중간 누락·손상 검사.
- 탐색기 실제 화면에서 Windows 11 첫 메뉴와 ZIP 하위 압축·해제·미리보기 항목을 확인하고 새 폴더 해제를 실행해 결과 파일을 확인했습니다.

최신 Windows 전체 빌드, 코어 통합·분할 포맷·메뉴·대화상자 리소스·자격 증명·업데이트 가드 검사를 통과했습니다. 별도 테스트 AppID의 설치·제거와 최종 설치를 확인했습니다. 설치된 앱 해시는 패키지와 일치하며 Windows 11 서명 메뉴 패키지는 Status Ok, 최신 DLL을 참조합니다.

Windows 실제 화면에서 폴더 아이콘과 원래 이름 표시를 확인했습니다. 실제 화면에서 비밀번호 마스킹·오암호 후 재입력·취소·올바른 암호로 목록 열기와 설정의 보기/글꼴/언어 항목 표시·취소를 확인했습니다. 설정의 모든 값 저장/재시작 조합과 새 편집 UI 전체는 미검증입니다.

## 완료하지 않은 검증과 제한

- 비밀번호 핵심 모달 동작과 설정 페이지 표시·취소는 실제 화면에서 확인했습니다. 설정 전체 저장 조합과 클립보드·외부 편집의 대화형 전체 흐름은 미완료입니다.
- Mac 대화형 UI와 Windows ARM64/PE 실기기, Mac 공증은 검증하지 않았습니다. Mac arm64/x86_64 빌드·코어 검사는 macOS 15 CI에서 통과했으며 Windows 전용 UI와의 동등성을 보장하지 않습니다.
- ZIP 복구는 비암호화 store/deflate의 완전한 로컬 레코드에 한정됩니다. 데이터 디스크립터·ZIP64·임의 손상 바이트를 복구하지 않습니다. 암호 복구는 후보 목록 안에서만 시도합니다.
- 클립보드 복사 파일은 프로그램 종료 시 정리합니다. 붙여넣기는 일반 파일만 지원합니다. 외부 편집은 텍스트 하나만 지원하며 저장·닫기 후 명시적으로 반영합니다.
- 영어는 기본 UI 번역이며 모든 안내/엔진 오류의 완전한 번역은 아닙니다. ISO는 데이터 이미지이며 부팅 이미지 제작을 지원하지 않습니다.
- 업데이트는 공개 안정 릴리즈만 대상으로 합니다. 신뢰된 동일 서명자의 새 릴리즈 다운로드·설치 전체를 실제 새 버전으로 실행한 검증은 별도입니다. 변조되거나 신뢰할 수 없는 설치 파일은 실행하지 않습니다.
- 암호가 코덱 CLI 인수로 전달되는 기존 제한은 남아 있습니다. INI와 로그에 저장하지 않으며 자격 증명 저장은 사용자가 명시적으로 요청할 때만 수행합니다.

## 서명과 설치

Windows 산출물은 CN=EoriniZip 로컬 테스트 인증서로 서명합니다. 개인 키는 업로드하지 않습니다. 이 PC는 사용자가 해당 인증서의 TrustedPeople 등록을 승인했으며, 다른 PC에서는 기본적으로 신뢰되지 않습니다. 다른 PC의 첫 메뉴 사용에는 사용자가 테스트 인증서를 명시적으로 신뢰하거나 일반 배포용 신뢰된 인증서로 다시 서명한 패키지가 필요합니다.

공개 릴리즈는 이 제한을 명시한 **pre-release**로 게시합니다. 서명 패키지가 등록되지 않으면 클래식 메뉴를 사용할 수 있으며 설치 프로그램이 실패를 안내합니다.
