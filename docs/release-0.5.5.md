# 어린이zip 0.5.5 · Windows x64

## 설치 오류 수정

0.5.4 설치 프로그램은 기존 파일과 새 파일의 내용이 같아도 탐색기 우클릭 메뉴 DLL을 교체하려고 했습니다. 탐색기가 DLL을 사용 중이면 설치 도중 `DeleteFile 실패, 코드 5`가 발생했습니다.

0.5.5는 기본 메뉴와 Windows 11 메뉴 DLL의 SHA-256을 각각 비교합니다. 같은 파일은 그대로 사용하고, 없거나 내용이 다르면 패키지의 파일을 설치합니다. 교체할 파일을 사용 중인 앱은 Windows Restart Manager를 통해 대화형 설치 화면에서 확인할 수 있습니다.

0.5.4 설치가 이 오류로 멈췄다면 **설치 취소**를 선택하고 0.5.5 설치 파일을 실행하세요. 0.5.4에서 추가한 대용량 압축 해제와 대상 드라이브 여유 공간 확인 기능도 포함합니다.

## Windows 검증 기록

| 설치 조건 | 확인한 결과 |
| --- | --- |
| 빈 폴더에 설치 | 두 메뉴 DLL이 모두 설치되었고 패키지의 해시와 일치했습니다. |
| 내용이 같은 두 DLL을 읽기 전용 공유로 열어 교체를 차단한 상태에서 재설치 | 잠금을 유지한 채 설치가 완료되었고 설치 로그에서 두 파일을 그대로 사용한 것을 확인했습니다. |
| 내용이 다른 두 DLL이 있는 폴더에 재설치 | 두 파일을 패키지 버전으로 교체했고 해시가 일치했습니다. |

설치 검증은 별도 폴더에서 탐색기 등록 및 제거 프로그램 생성을 끈 테스트 설치본으로 수행했습니다. Windows x64 앱의 코어 단위 테스트도 통과했습니다.
